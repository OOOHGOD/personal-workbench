# DC的个人工作台

单人使用的个人信息系统语境：记录工作、学习、留学申请与简历证据，并约定这些信息何时出现、怎样算没丢。本表只收这套语境里的专有词，不收通用编程概念，也不写实现细节或技术选型。

## Language

**工作台**:
一套约定：记录什么、何时出现、怎样算没丢。它不指任何界面、页面或程序；形态是另一个独立决策。
_Avoid_: 系统、应用、网站、页面

**记录**:
工作台里最小的事实单元，也是唯一需要保存的东西。同一个事实只存在一份，可以同时用于日报、学习统计与简历；业务类别只是查看它时的筛选方式，不构成另一种东西。
_Avoid_: 条目、任务、表行、日志、分类

**用途标记**:
标注一条记录可用于日报、学习统计或简历的标签。一条记录可以有多个用途标记。
_Avoid_: 分类、类型、字段、表

**自动**:
信息无需人主动查找即可呈现的性质。判定为零点击到达且内容已预先生成；此外允许在约定时刻由外部服务主动发出提醒，具体触发方式与通道见决策记录。
_Avoid_: 定时任务、后台同步、实时一致

**不丢**:
任意时刻都能从单一主副本取得一份完整、开放格式、可读、可被别处导入的全量快照，且该快照能被实际恢复的性质。判定看快照能否恢复，不看多个副本是否实时一致。
_Avoid_: 实时同步、三处一致、离线可用、缓存数据

**证据**:
一条记录被标记为可用于简历时，它所提供的可核实内容；也是月更产出的唯一内容形态。月更只产出证据清单与按用途标记分组的证据段落，不产出完整简历文件。
_Avoid_: 成果、成果条目、月度成果清单、简历增量、简历文件
