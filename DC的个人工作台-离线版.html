备份与恢复

JSON 备份包含任务、项目、调研、速记、资料、报告存档、AI 记录、学习、申请全部记录及格式版本（v3），导入前可预览，支持合并或替换；v2 老备份也能导入（学习/申请按空处理）。

布局与外观

「今日工作」页支持 iCloud 式小组件摆放：点「整理小组件」，按住卡片右上角 ⠿ 把手拖到想要的位置；同一张卡片还能用 S/M/L 三档调大小（S 紧凑只留关键项、M 标准、L 占整行展开全部）。摆放与尺寸保存在本机浏览器（如实标注：暂不跨设备同步，换设备需重新摆）。

某些情况不允许缩到 S：本周概览（含图表放不下）、今天要处理的（逾期与待跟进必须完整可见）、核心项目动态在有卡点项目时、今日重点超过 2 项时——S 按钮会置灰，点它会告诉你原因。

示例数据

示例记录带有「示例」标记，清空时只删示例，不影响你的真实数据。

优先级说明

  • 重要且紧急直接影响项目交付或当天要交的东西，优先做
  • 重要不紧急影响长期目标，每天安排固定时间推进
  • 紧急不重要别人催但价值有限，快速处理或委婉推迟
  • 一般有空再处理，可批量安排

使用说明（如实标注）

  • 数据存在云端资料库数据表：手机、电脑登录同一账号打开本页即共用；直接改数据表，页面会自动收到更新。
  • 离线 HTML 版（可下载）仅支持查看缓存数据，本地新增需通过导出/导入 JSON 与云端合并，暂不支持自动补同步——此能力如实标注为「半自动」。
  • 日报周报已上线：数据来自任务完成记录 + AI 工作记录（10 秒记一条），自动去重、双版本（自用/领导）、导出真实 .docx 与 Markdown、一键存档云端。
  • 个人学习与留学申请已上线（第 3 期）：学习记录按「学习日期 + 时长」统计；申请截止日 14 天内自动进「今日工作」提醒；两者只进自用版日报周报，不进领导摘要。
  • 简历月更已上线（第 4 期）：每月汇总上月「证据型成果」（完成的任务 / 项目里程碑 / 学习成果），一键生成简历增量草稿并存版本快照，历史版本可查看与回滚；每月 1-7 日若上月未出快照会在本模块顶部提醒。
