## 1. 测试策略

四层金字塔，全部可重复执行、纳入回归：

```
        ┌──────────────┐
        │  UI/UX 实测  │  Chrome headless 双视口（桌面 1440×900 / 手机 390×844）
        ├──────────────┤
        │   集成测试   │  云端 9 表真实 CRUD 回环 + 发布产物校验
        ├──────────────┤
        │   单元测试   │  jsdom + mock SDK + 真实服务端 schema 校验
        ├──────────────┤
        │  静态 lint   │  schema 规范 / DSDK 用法 / 页面质量三道门
        └──────────────┘
```

**核心原则：**
1. mock 层用**真实服务端 schema** 校验每次写入（选项、字段名错当场报错，对齐 11607 类线上错误）
2. 发布产物必须拉回来复测（防止「源文件对、发布产物错」）
3. 改 UI 必测手机视口（390×844 是验收基线）

## 2. 单元测试（tests/unit_test.js）

- **运行**：`NODE_PATH=<jsdom所在node_modules> node unit_test.js`（可用 `HTML_PATH` 环境变量指向任意副本，如发布产物/离线版）
- **机制**：JSDOM 加载 workbench.html，`beforeParse` 注入 mock SDK（含 schema 校验）+ `URL.createObjectURL` 捕获；`runScripts:"dangerously"` 真实执行内联 JS
- **规模**：20 场景 / 239 断言（场景 20：今日任务看板/指标联动/projectId 关联/项目详情/弹窗焦点/hash 路由）

| 场景 | 覆盖 |
|---|---|
| 1-7 | 初始化渲染、自动顺延幂等、快速记录、完成/取消、顺延明天、今日重点上限、过滤器搜索 |
| 8-12 | 转任务、编辑弹窗与截止留痕、新建任务、项目统计、清空示例 |
| 13-14 | 视图切换（含抽屉路径）、本地路径显示 |
| 15-17 | 日报周报、小组件摆放持久化、尺寸档位 |
| 18 | 第 3 期：学习/申请视图、筛选、统计口径、截止提醒、转任务、报告隔离、备份 v3 |
| **19** | **底部导航 5 主按钮 + 更多抽屉**：按钮数=5、抽屉 6 视图、开关与 aria、切换自动收起、active 联动、收起按钮、点外部收起、桌面侧边栏完整性 |

## 3. 集成测试（tests/integration_test.py）

- **运行**：`python integration_test.py`（走 space_api，需运行时注入认证）
- **规模**：95 断言，覆盖：
  - 9 张云表 list/add/update/delete CRUD 回环（真实云端）
  - 页面节点校验：web 类型、下挂 9 张子表、页面-数据库关系
  - 发布产物下载与校验（SDK 注入点、报告逻辑、refreshAll、双向同步订阅）
  - 示例数据完整性（数量、逾期演示、临期申请演示、无真实数据残留）

## 4. UI/UX 实测（tests/ux_review.js）

- **运行**：`NODE_PATH=<playwright-core所在> node ux_review.js`
- **机制**：本地 HTTP 服务（18765 端口）伺服 workbench.html + `addInitScript` 注入 mock SDK 与种子数据（发布链接在 headless 环境会重定向到营销页，故走本地通道）；双视口逐视图截图、弹窗交互、导航度量、控制台错误捕获；输出 `ux_shots/` 截图 + findings
- **断言维度**：导航溢出（scrollWidth vs clientWidth）、换行数、触控目标最小宽度、弹窗宽度、页面横向滚动、JS 控制台错误、抽屉可达性（打开→点击→切换→自动收起）

### 4.1 中期审查结论（2026-10-19）

**桌面端（1440×900）全过**：今日申请截止提醒、自用版日报含学习/申请段、领导摘要隔离、申请页截止卡倒计时、无 JS 错误。

**手机端（390×844）发现并修复：**

| 级别 | 发现 | 处置 |
|---|---|---|
| **P0** | 底部导航 10 按钮，scrollWidth 628 > 390，学习/申请/报告/设置被截断**不可达** | 改为 5 主按钮 + 「更多」抽屉；复测 `{"btnCount":5,"navScrollWidth":390,"overflow":false}`，6 个抽屉视图全部可达，0 发现 |
| P2（噪音） | btn-mini 高度 0 | 隐藏元素测量噪音，非问题 |

## 5. 静态 lint 三道门

| 门 | 命令 | 结果 |
|---|---|---|
| lint_schema（R1-R10） | 9 张 canonical_*.json 逐表 `--stdin` | MINDX_LINT_OK ×9 |
| lint_database_sdk_usage | `--html workbench.html --schema-file schema_srv_merged.json` | MINDX_DBSDK_LINT_OK |
