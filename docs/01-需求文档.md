# 需求文档 · DC的个人工作台

- **项目代号**：personal-workbench
- **版本**：v3.0（第 1-3 期已交付，第 4 期规划中）
- **维护人**：用户本人（唯一用户，单人使用）
- **更新日期**：2026-10-19

---

## 1. 项目背景与目标

用户需要一套打通「工作 + 学习 + 留学申请」的个人效率系统，替代散落在备忘录、聊天记录、Excel 里的信息碎片。核心诉求：

1. **每日工作闭环**：早上知道今天做什么，晚上能一键生成日报。
2. **学习与申请不丢线**：学习记录可统计、留学申请截止有提醒。
3. **数据自主可控**：云端可协作、可导出备份，本地有离线副本。
4. **零运维成本**：不租服务器、不跑常驻进程，打开网页即用。

## 2. 用户与使用场景

| 场景 | 描述 |
|---|---|
| 每日晨间 | 打开「今日工作」视图，查看逾期任务、卡住项目、今日重点 |
| 随手捕获 | 顶部快速记录条一句话存入收集箱，事后再整理 |
| 工作过程 | 任务状态流转（收集箱→进行中→已完成）、顺延、拆分、转任务 |
| 晚间复盘 | 生成自用版日报（含学习/申请）与领导摘要（不含私密内容） |
| 学习复盘 | 记录学习条目（课程/语言备考/技术），统计本周时长 |
| 申请跟进 | 维护留学申请（学校/专业/截止日/下一步），临期自动提醒 |
| 数据安全 | 定期导出 JSON 备份（9 表全覆盖），换设备可导入恢复 |

## 3. 功能需求

### 3.1 第 1 期（已交付）——工作核心

- FR-101 任务管理：标题/分类/状态/计划日期/截止日期/备注，收集箱→完成全流转
- FR-102 今日视图：逾期任务、卡住项目、到期跟进、今日重点（上限 3 条）
- FR-103 快速记录：一句话 → 收集箱
- FR-104 自动顺延：计划日期为过去的任务自动滚到今天并留痕（顺延次数/原计划日期）

### 3.2 第 2 期（已交付）——工作扩展

- FR-201 项目管理：项目卡、按关联项目实算进度、逾期统计
- FR-202 需求调研：调研记录 + 「转任务」
- FR-203 速记：速记条目 + 转任务/转调研
- FR-204 资料库：资料条目、本地路径复制
- FR-205 日报周报：自用版（全量）+ 领导摘要（工作相关），一键复制
- FR-206 AI 工作记录：记录 AI 辅助工作

### 3.3 第 3 期（已交付）——学习与申请

- FR-301 个人学习：学习条目（类型/科目/时长/状态/笔记）、本周完成统计（示例数据不计入）
- FR-302 留学申请：申请档案（学校/专业/截止日期/状态/优先级/下一步）
- FR-303 截止提醒：截止日 14 天内且状态为进行中的申请，进今日视图提醒盒，按截止日排序、倒计时着色（逾期红/今天橙/临期黄）
- FR-304 转任务：学习条目与申请的「下一步」一键转成今日任务，分类自动带
- FR-305 报告隔离：学习与申请只进自用版日报，领导摘要默认不含

### 3.4 第 4 期（规划中）

- FR-401 简历月更：每月 1 日自动汇总当月证据型成果，生成简历增量
- FR-402 简历版本管理：历史版本可回滚

### 3.5 横切需求（全期）

- FR-X01 数据备份：JSON 导出（formatVersion=3，覆盖 9 表）、导入合并
- FR-X02 示例数据：内置带「是否示例=true」标记的演示数据，可一键清空，不污染真实数据与统计
- FR-X03 响应式：桌面侧边栏导航；手机底部 5 主按钮 + 「更多」抽屉（项目/调研/速记/资料/报告/设置），全部视图触控可达
- FR-X04 双形态：WorkBuddy 资料库在线页（可写云端）+ 离线 HTML 副本（只读缓存 + JSON 导入导出）

## 4. 非功能需求

| 编号 | 需求 | 验收口径 |
|---|---|---|
| NFR-01 | 单文件零依赖 | workbench.html 全内联 JS/CSS，无外链 CDN |
| NFR-02 | ES5 兼容 | JS 语法全 ES5，旧浏览器可跑 |
| NFR-03 | 安全 | 所有用户数据入 DOM 前经 `esc()` 转义 |
| NFR-04 | 质量 | 单测 194 断言、集成 95 断言、lint 三道门全过 |
| NFR-05 | 手机可用 | 390px 视口无横向溢出，触控目标 ≥ 40px |
| NFR-06 | 幂等脚本 | 建表/灌数据脚本可重复执行不重复写入 |

## 6. 约束与边界

- **不做**：多人协作、权限体系、服务端定时任务（第 4 期月更依赖平台 automations，不走自建后端）
- **平台锁定**：云数据读写依赖 WorkBuddy 资料库 SDK（`window.__SMART_PAGE__.database`）；离线版只读
- **仓库边界**：仓库根的 Cloudflare D1 独立后端版（client/server/migrations）为另一并行实验，不属于本项目需求范围，不入本套文档
