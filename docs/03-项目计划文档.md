## 5. 里程碑与节奏

- **发布节奏**：每期一个 git tag（第 1-3 期对应提交序列），期中修复直接提交 main
- **验证节奏**：每期交付后必跑「中期验证三件套」（功能回归 + UX 实测 + lint）；改 UI 必须带手机视口复测
- **同步节奏**：关键节点（开发完成 / 修复完成 / 文档完成）即 git 提交；发布与离线版同步在每次云端变更后立即执行

## 6. 资源与协作

- 单人项目：用户即产品 owner + 唯一用户；Agent 负责开发/测试/发布执行
- 外部依赖：WorkBuddy 资料库（云表 + 页面 + SDK + 发布链路）、GitHub（版本管理）
- 工具链固定：python（云脚本）+ node（单测/UX 实测）+ skill-library lint 三件套
