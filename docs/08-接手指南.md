## 2. 换账号继续：两种情形

### 情形 A：新账号能访问同一资料库空间（推荐，最省事）

页面节点与 9 张表都在个人空间 `90RRiESzDskeLJpYNDxTMX` 下。只要新账号对该空间有权限：

1. 直接打开在线版链接，或在资料库里打开页面节点 `Uo1qyjrSZ67qmecuVnAxXU`
2. 改 `workbench_build/workbench.html` → 按 §4 流程测试与发布
3. 云表 ID 无需改动

### 情形 B：新账号是全新空间（需要重建数据表）

旧空间不可读时（本项目 2026-10-19 就遇到过一次），按顺序执行：

```bash
cd workbench_build
python rebuild_tables.py      # 从 schema_srv_*.json 幂等重建 9 张表 → 输出 dbid_map.json
python fetch_schemas.py       # 拉取新表真实 schema 落盘
python gen_canonical.py       # 生成 canonical_*.json + schema_srv_merged.json（lint 用）
python seed_samples_v3.py     # 灌示例数据（是否示例=true，可一键清空）
```

然后把新表 ID 写回源文件（文件头部的 `DB_TASKS`…`DB_APPLY` 九个常量，以及 HTML 里 `data-sp-database-id` 绑定的任务表 ID），再走发布：

```bash
python <skill-library>/page/import_html.py workbench.html \
  --node-block-id <新页面节点> --databases '[{"id":"<新tasks>"},{"id":"<新projects>"},…共9张]'
python <skill-library>/page/publish_page.py --node-id <新页面节点>
```

> 重建后必须跑一次完整回归（单测 + 集成 + lint + UX 实测），集成测试会把新 ID 的云端 CRUD 全部回环验证一遍。

## 4. 常用命令速查

```bash
cd workbench_build/tests
export NODE_PATH="C:\Users\DC\.workbuddy\binaries\node\workspace\node_modules"

# 单元测试（239 断言 / 20 场景；HTML_PATH 可指向发布产物或离线版）
node unit_test.js
HTML_PATH="pub_check\workbench.html" node unit_test.js
HTML_PATH="..\..\个人工作学习工作台-离线版.html" node unit_test.js

# UI/UX 浏览器实测（桌面 1440×900 + 手机 390×844，截图输出 ux_shots/）
node ux_review.js

# 云端集成测试（9 表 CRUD 回环 + 发布产物校验，95 断言）
python integration_test.py
```

lint 三门（改完代码必跑，详见 `docs/04-测试文档.md`）：

```bash
P=<skill-library>/page
for t in tasks projects research notes resources reports airecords study apply; do
  cat canonical_$t.json | python $P/lint_schema.py --stdin; done        # 全部 MINDX_LINT_OK
python $P/lint_database_sdk_usage.py --html workbench.html --schema-file schema_srv_merged.json
python $P/lint_page_quality.py --html workbench.html --ack "PQ001/PQ005 已知误报…"
```

发布（详见 `docs/06-部署文档.md`）：

```bash
python $P/import_html.py workbench.html --node-block-id Uo1qyjrSZ67qmecuVnAxXU --databases '[…9 张表 id…]'
python $P/publish_page.py --node-id Uo1qyjrSZ67qmecuVnAxXU
python $P/download_page_artifacts.py --node-id Uo1qyjrSZ67qmecuVnAxXU --source publish --out-dir tests/pub_check
# 产物复测 → 离线版同步（直接 cp，零定制差异）→ 离线版复测
```

推送（Windows 偶发 TLS 握手失败，统一降级 HTTP/1.1）：

```bash
git -c http.version=HTTP/1.1 push origin main
```
