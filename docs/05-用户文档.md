# 用户文档 · 个人工作学习工作台

- **适用版本**：v3.0（学习 + 留学申请已上线）
- **更新日期**：2026-10-19

---

## 1. 两种打开方式

| 方式 | 地址 | 能力 |
|---|---|---|
| **在线版（推荐）** | https://workbuddy.link/p/Uo1qyjrSZ67qmecuVnAxXU | 全功能，数据实时存云端 |
| 离线版 | 本仓库 `个人工作学习工作台-离线版.html`（浏览器直接打开） | 只读缓存数据；写操作需导出/导入 JSON 与云端合并（半自动） |

> 在线版数据存于你的 WorkBuddy 个人资料库，换设备登录同一账号即可继续使用。

## 2. 界面总览

**桌面**：左侧边栏列出全部视图；**手机**：底部 5 个主按钮（今日/任务/学习/申请/更多），其余视图（项目/调研/速记/资料/报告/设置）点「更多」从抽屉进入，选完抽屉自动收起。

## 3. 每日工作流（推荐节奏）

### 早上：看「今日工作」
1. 打开工作台，默认进入今日视图
2. 看 4 个提醒区：**逾期任务 / 卡住项目 / 到期跟进 / 申请截止提醒**（截止 14 天内自动出现，红=已逾期、橙=今天截止、黄=剩 3 天内）
3. 今日重点最多设 3 条（☆ → ★）

### 白天：随手记
- 顶部**快速记录条**：一句话回车 → 自动进任务「收集箱」，事后再整理
- 任务行内按钮：`完成`、`顺延明天`、`重点`、`编辑`、`拆分`
- 计划日期过了没做完？第二天打开自动滚到今天，并记录顺延次数

### 晚上：生成日报
1. 进「报告」视图 → 选 今天 / 本周 / 上周
2. 生成后有两个文本框：
   - **自用版**：全量记录（含「个人学习与留学申请」段，仅自己可见的内容不会外泄到摘要）
   - **领导摘要**：只含工作相关，可直接复制发给领导

## 4. 学习记录（第 3 期）

1. 「学习」视图 → **记学习**
2. 填类型（课程学习/语言备考/技术实践…）、科目、时长（分钟）、状态
3. 「本周完成 N 条 / 共 M 分钟」自动统计——**示例数据不计入统计**
4. 「转任务」：把这条学习排成今天的计划任务

## 5. 留学申请（第 3 期）

1. 「申请」视图 → **加申请**：学校、专业、**截止日期**、状态、优先级、下一步
2. 截止日 14 天内且「进行中」的申请自动进今日提醒盒，按截止先后排序
3. 逾期会显示「已逾期 N 天」
4. 「转任务」：把「下一步」一键变成任务，分类自动带上

## 6. 数据安全：备份与恢复

- **导出**：设置视图 → 导出备份 → 得到 JSON 文件（覆盖全部 9 张表，含学习/申请）
- **导入**：换设备或误删时，导入 JSON 与云端合并
- 建议频率：每周一次，或大批量录入后立即一次

## 7. 示例数据

首次使用时表里有带「示例」徽标的演示数据（含 1 条逾期任务、1 条临期申请，用于演示提醒功能）。熟悉后到**设置 → 清空示例数据**一键清除，真实数据不受影响。

## 8. 常见问题

| 问题 | 答案 |
|---|---|
| 手机上找不到「项目/报告/设置」 | 点底部「更多」按钮，从抽屉进入 |
| 显示「离线模式」 | 你在用离线版 HTML；要写数据请打开在线版链接 |
| 学习记录没进本周统计 | 只统计「已完成」且完成日期在本周的；示例数据不计入 |
| 日报里没有学习内容 | 学习/申请只在**自用版**，领导摘要默认不含（隐私设计） |
| 任务计划日期是昨天，今天不见了 | 自动顺延已把它滚到今天，任务行可看顺延次数与原计划日期 |
| 点保存报错 | 多为网络抖动，稍等重试；持续失败请参照维护文档检查云表状态 |
